Caelestia: Changelog & Design Specification

1. Network Speed in Taskbar

Feature

Added real-time network speed monitoring to the status bar with detailed history visualization.

Technical Implementation

  • Service: Integrated with NetworkUsage service for data collection.
  • Component: Added netSpeed loader in StatusIcons.qml.
  • UI: Compact mono-font display in the bar; detailed popout in NetworkSpeed.qml.
  • Visualization: Includes a dual-line sparkline graph for upload and download history.

2. Corner Action Support (Hot Corners)

Feature Fixes

Implemented hot corners with proximity-based visual feedback and extensive configuration.

Technical Implementation

  • Tracking: Uses hyprctl cursorpos -j via a Process for reliable global mouse tracking.
  • Feedback: Proximity-based glow effect that scales and fades as the cursor nears a corner.
  • Trigger: 10x10px trigger area with configurable activation delay.
  • Persistence: Settings saved via CornerSettings service.
ComponentPath
Logic & UImodules/CornerActions.qml
Settings Serviceservices/CornerSettings.qml

3. Hyprland 0.55 Compatibility

Fix

Updated Hyprland IPC communication to support version 0.55 dispatch command format.

Changes

  • Updated Hypr.dispatch calls to use the new structured string format.
  • Replaced legacy commands with modern counterparts:
    • workspace → hl.dsp.focus({ workspace = ... })
    • movetoworkspace → hl.dsp.window.move({ ... })
    • togglespecialworkspace → hl.dsp.workspace.toggle_special(...)

4. Workspace Manager & Auto-Compact

Feature Refactor

Centralized workspace management logic and added an "Auto-Compact" feature to eliminate gaps between workspaces.

Technical Implementation

  • WorkspaceManager: A new singleton for handling complex workspace operations.
  • Auto-Compact: Dynamically moves windows to fill empty workspaces, maintaining a contiguous sequence.
  • Smarter Cycling: cycleWorkspace now wraps around based on the actual number of occupied workspaces + 1.
  • Dynamic Bar: The workspace indicator in the bar now adjusts its count based on purgeEmpty settings.
